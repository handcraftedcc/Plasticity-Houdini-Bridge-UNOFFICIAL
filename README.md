# Plasticity Houdini Bridge

Pull-based Plasticity mesh bridge for Houdini Python Snippet and Python SOP
nodes. See [SETUP_GUIDE.md](SETUP_GUIDE.md) for installation and first use, or
[DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) for scope and design.

Install the repository with a Houdini package file pointing `PLASTICITYBRIDGE`
at this directory, then create a Python Snippet SOP and run the shelf setup
script in `scripts/python/shelf/create_plasticity_fetch_parameters.py`.
